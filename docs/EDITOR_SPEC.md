# JustMosaic! 描画オブジェクト編集の基本仕様

JustMosaic!で作成したすべてのモザイクおよび注釈オブジェクトは、
作成後も選択・移動できなければならない。

この仕様は描画ツールの種類に依存しない。

新しい描画ツールを追加する場合も、
明示的に例外を定義しない限り選択・移動機能を必須とする。

既存オブジェクトの選択・移動機能を失わせる変更は仕様違反とする。

## 直接操作の恒久仕様

すべての描画オブジェクトは、描画後に同じツールのまま直接ドラッグして移動できること。

移動のために専用ツールへ切り替える操作を要求してはならない。独立した選択モードを設けない。

今後追加される描画ツールも、この操作仕様に準拠すること。特定のツールだけ操作方法を変えてはならない。

## 操作

- 空白からドラッグすると現在の描画ツールで新規作成する。作成直後はそのオブジェクトを選択する。
- 既存オブジェクトを押すと選択する。同じ描画ツールのまま、ドラッグで移動する。他の描画ツールを使用中でも既存オブジェクトの編集を優先する。
- 選択済みの図形は右下ハンドル、矢印は両端点をドラッグしてサイズ・方向を変更する。専用の編集ツールは不要。
- 空白を押すと選択を解除する。ブラシは空白のタップでも新しい点を描画し、その点を選択する。
- 新しい図形は空白から既存図形へドラッグして重ねられる。既存図形の内側から描き始めたい場合は、その位置を450ms長押ししてからドラッグする。PCではAlt＋ドラッグも使用できる。この指定は1回の描画ジェスチャーだけに適用し、ツールやモードを切り替えない。
- 移動開始前の4 CSS px未満の揺れはクリック／長押しとして扱う。移動開始、離す、キャンセル、2本指への切替、ツール変更、画像変更、Undo/Redoで長押し待機を解除する。ハンドルは長押しによる描画への切替対象外。

| オブジェクト | 移動 | サイズ変更 |
|---|---|---|
| 矩形モザイク | 必須 | 右下ハンドル |
| 丸囲みモザイク | 必須 | 右下ハンドル |
| ブラシモザイク | 軌跡全体の移動が必須 | 任意（現在は未対応） |
| 矩形注釈 | 必須 | 右下ハンドル |
| 丸囲み注釈 | 必須 | 右下ハンドル |
| 矢印注釈 | 必須 | 両端点で長さ・方向を変更 |

注釈はモザイクより前面。同じレイヤーでは後に作成したオブジェクトを優先する。選択済みハンドルの操作を優先する。図形の内部も選択可能。ブラシは軌跡、矢印は線と矢尻の近傍で選択する。タッチではハンドルの判定範囲を広くする。

編集は元画像座標で処理し、移動・サイズ変更を各1回のUndo/Redo対象とする。クリックだけでは履歴を追加しない。キャンセルや2本指への切替では編集中の変更を破棄する。Space＋ドラッグ・中ボタンはパン、2本指はズーム・パンとして優先する。

元画像座標は小数点以下6桁に正規化し、浮動小数点誤差によってモザイクの整数境界で切り出し範囲が変わることを防ぐ。

保存は元画像と解決済み履歴から再描画する。移動先へモザイクを適用し、注釈の色・線幅を維持する。選択枠・ハンドルは編集画面だけに表示し保存に含めない。既存の強度・線幅設定の履歴全体への反映は維持する。

## 実装と検証

`js/objects.js` の `DRAWING_TOOLS` に全描画ツールを登録し、共通の当たり判定・境界・ハンドル・編集処理へ接続する。既存の `shapeEdit` 履歴形式を維持する。

新しいツールは `tests/mosaic-smoke.js` に独立した座標・保存画素の期待値を追加する。UIとレジストリ、レジストリとテストの対応を自動検証する。全種類についてマウス・タッチによる作成直後の選択、ツールを切り替えない直接移動、座標、Undo/Redo、保存PNGを検証し、必須サイズ変更も同様に検証する。長押しによる重ね描きと微小な入力誤差も検証する。保存の比較では独立した期待座標から描画した全画素と、実際の履歴から描画した全画素の双方に厳密一致させる。

ブラウザテストはPC表示とスマートフォン表示（HiDPI・タッチ対応）の両方で実行する。実UIも全種類をネイティブのマウス／タッチ入力で操作し、直接移動、Undo/Redo、保存、長押し重ね描きを検証する。

`npm ci` と `npm test` でブラウザ回帰テストを実行する。GitHub Actionsでも同じテストを実行する。
