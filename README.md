# JustMosaic!

画像をブラウザ内だけで読み込み、矩形・丸囲み・ブラシでモザイク加工し、矩形・丸囲み・矢印の注釈を追加して保存できる静的Webアプリです。画像は元の解像度で再描画されます。

## Privacy

ユーザーが選んだ画像は外部サーバーへアップロードされません。画像の読み込み、編集、書き出しはすべてブラウザのメモリ内で行われ、出力時にはEXIFメタデータも引き継ぎません。外部API、Analytics、CDN、外部フォントは使用していません。

## 主な機能

- JPEG / PNG / WebPの読み込みと同形式での保存
- ドラッグ＆ドロップ、端末のファイル選択
- 矩形・丸囲み・ブラシモザイク
- モザイク強度、ブラシサイズの調整
- 矩形・丸囲み・矢印注釈の色・線幅調整
- Undo / Redoとキーボードショートカット
- マウスホイール、ボタン、ピンチによるズーム
- Space＋ドラッグ、2本指操作によるパン
- 元画像の解像度を維持した書き出し

## 技術構成

- HTML
- CSS
- Vanilla JavaScript (ES Modules)
- Canvas 2D API
- GitHub Pages

ビルド処理や外部パッケージは不要です。

## ローカル実行

ES Modulesを使用しているため、リポジトリのルートでHTTPサーバーを起動してください。

```sh
python3 -m http.server 8000
```

その後、ブラウザで `http://localhost:8000` を開きます。

## GitHub Pages

リポジトリの Settings → Pages で、公開元をブランチのルートに設定するとそのまま公開できます。

すべての描画オブジェクトは、描画後に同じツールのまま直接ドラッグして移動できます。移動のために専用ツールへ切り替える操作は不要で、独立した選択モードはありません。今後追加される描画ツールも、この操作仕様に準拠します。図形は右下のハンドル、矢印は両端点でサイズ・方向を変更できます。ブラシは軌跡全体を移動できます。編集はUndo / Redoに対応し、選択枠・ハンドルは保存画像に含まれません。

空白からのドラッグは新規描画、既存オブジェクトを押すと選択して移動します。重ね描きは空白から開始するか、図形上で長押し後にドラッグしてください（PCではAlt＋ドラッグも使用できます）。PC・スマートフォンで共通の操作です。

恒久的な基本仕様は [描画オブジェクト編集仕様](docs/EDITOR_SPEC.md) を参照してください。開発時の必須事項は [AGENTS.md](AGENTS.md) に記載しています。

## 自動テスト

Node.js 20以降で `npm ci`、`npx playwright install chromium`、`npm test` を実行します（アプリ本体に外部パッケージは不要）。PC表示・スマートフォン表示の両方で、全6種類の直接操作と保存を確認します。GitHub Actionsでも自動実行します。手動確認はHTTPサーバー経由で `tests/mosaic-smoke.html` を開いてください。
