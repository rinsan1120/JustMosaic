# JustMosaic!

画像をブラウザ内だけで読み込み、矩形またはブラシでモザイク加工し、矢印や丸囲みの注釈を追加して保存できる静的Webアプリです。画像は元の解像度で再描画されます。

## Privacy

ユーザーが選んだ画像は外部サーバーへアップロードされません。画像の読み込み、編集、書き出しはすべてブラウザのメモリ内で行われ、出力時にはEXIFメタデータも引き継ぎません。外部API、Analytics、CDN、外部フォントは使用していません。

## 主な機能

- JPEG / PNG / WebPの読み込みと同形式での保存
- ドラッグ＆ドロップ、端末のファイル選択
- 矩形モザイク、ブラシモザイク
- モザイク強度、ブラシサイズの調整
- 矢印、丸囲み注釈の色・線幅調整
- Undo / Redoとキーボードショートカット
- マウスホイール、ボタン、ピンチによるズーム
- Space＋ドラッグ、2本指操作によるパン
- 元画像の解像度を維持した書き出し

## 技術構成

- HTML
- CSS
- Vanilla JavaScript (ES Modules)
- Canvas 2D API
- GitHub Pages

ビルド処理や外部パッケージは不要です。

## ローカル実行

ES Modulesを使用しているため、リポジトリのルートでHTTPサーバーを起動してください。

```sh
python3 -m http.server 8000
```

その後、ブラウザで `http://localhost:8000` を開きます。

## GitHub Pages

リポジトリの Settings → Pages で、公開元をブランチのルートに設定するとそのまま公開できます。
